# Baúl — galería para el Redmi Note 14 Pro

## Lo principal
- **Fotos:** línea de tiempo por día, con filtros (Todo, Fotos, Videos, Favoritos, Capturas).
  **Pellizca** para cambiar el tamaño de las miniaturas.
- **Selección cómoda:** mantén presionada una foto y **arrastra** para elegir muchas.
  Mientras seleccionas, **un toque en cualquier parte** marca o desmarca (nunca abre la foto).
  El círculo junto a cada día selecciona el día completo.
- **Acciones:** Compartir, Mover (a un álbum o uno nuevo), Favorito, Papelera.
- **Álbumes:** por carpeta, más Favoritos, Videos y Papelera (restaurar o eliminar).
- **Visor:** desliza entre fotos, pellizca o toca dos veces para zoom, Info (cámara, exposición, ubicación).
  Los videos se abren en Pelis.
- **Editar:** Recortar (Libre, Original, 1:1, 4:3, 3:4, 16:9, 9:16), Girar, Voltear, Enderezar;
  Ajustes (exposición, brillo, contraste, saturación, calidez, luces, sombras, viñeta);
  Filtros de Claroscuro con Intensidad y Rojos. Siempre guarda una **copia**.

## Área privada
1. Ajustes › **Clave privada** › Crear.
2. Toca la lupa y **escribe tu clave** como si buscaras algo: se abre el área privada.
3. Con el área abierta aparece la acción **Privado** al seleccionar fotos: las saca de la galería
   (ninguna app las ve) y las guarda aquí. **Sacar** las devuelve a su álbum.
4. Se cierra sola al salir de la app, o con el candado.

**Importante:** si desinstalas Baúl o borras sus datos, el área privada se borra.
Usa **Respaldar** (ícono de nube) y guarda el archivo `.baul` en tu computadora.
Si olvidas la clave, no hay forma de recuperarla.

## Sin confirmaciones
Ajustes › "Borrar y mover sin confirmar" › Activar (Administración de medios).

## Compilar
Igual que Pelis y Claroscuro: repositorio nuevo en GitHub › Actions › descargar **Baul-apk**.
